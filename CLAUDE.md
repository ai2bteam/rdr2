# RDR2 Asset Library — правила для Claude

Это библиотека медиа-материалов (картинки, скриншоты, логотипы, арты) для создания видеорядов про Red Dead Redemption 2. Claude сам модерирует репозиторий по этим правилам.

## Структура

```
characters/    персонажи (Arthur, John, Dutch, банда, NPC) — подпапка на персонажа
locations/     локации (Saint Denis, Valentine, Blackwater...) — подпапка на локацию
transport/     лошади, дилижансы, поезда, лодки
animals/       живность и легендарные животные
weapons/       оружие
logos/         логотипы (Rockstar, RDR2, внутриигровые бренды)
screenshots/   скриншоты из трейлеров/геймплея
artwork/       официальные арты, постеры, ключевые арты
maps/          карты и фрагменты карты
ui/            интерфейс, шрифты, HUD
misc/          всё, что не подошло выше
```

Подпапки создавай по мере накопления: если в папке 3+ файла про одну сущность — выноси в подпапку (`characters/arthur_morgan/`).

## Правила для каждого ассета

1. **Имя файла** — человекочитаемое, snake_case, на английском: `arthur_morgan_campfire_trailer3_01.jpg`, не `IMG_2041.png`.
2. **Sidecar-описание** — рядом с каждым файлом `имя.md` с фронтматтером:

```markdown
---
title: Arthur at the campfire
source: RDR2 Trailer 3 (timestamp 0:43)
type: screenshot
tags: [arthur, campfire, night, gang-camp]
resolution: 1920x1080
license: Rockstar promo / fair use
added: 2026-07-24
---

Артур сидит у костра в лагере банды, ночное освещение. Подходит для
сцен про быт банды Ван дер Линде.
```

3. **INDEX.md в корне каждой папки** — таблица: файл → одна строка описания. Обновляй при каждом добавлении/удалении.
4. **Корневой INDEX.md** — дерево всей библиотеки. Это первое, что читаешь при поиске ассета.

## Модерация (делай сам при каждой работе с репо)

- Новый файл без описания → создай sidecar `.md` (посмотри картинку через Read и опиши её).
- Файл с мусорным именем → переименуй по конвенции.
- Дубликаты → удали худший по качеству.
- Пережатые копии того, что уже есть в лучшем качестве, не добавляем.
- Фанатский контент — только с указанием автора (`license: Fan-made / community`).
- Видео >100 МБ в git не пушить (`*.mp4` в .gitignore) — кадры извлекать через ffmpeg.
- После изменений → обнови INDEX.md и закоммить с осмысленным сообщением (от ai2bteam, без Co-Authored-By).

## Поиск ассетов

При задаче «найди картинку X для видео»: сначала `INDEX.md` корня → INDEX нужной папки → фронтматтер-теги (`grep -r "tags:.*слово" --include="*.md"`).
