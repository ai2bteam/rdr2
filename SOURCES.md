# Источники материалов по RDR2

Реестр проверенных сайтов для пополнения библиотеки. Обновляй при находке новых.

| Источник | Что даёт | Доступ | Заметки |
|---|---|---|---|
| gtabase.com/red-dead-redemption-2/ | галереи: 871 скриншот (Story/Trailers/RDO), 258 артов (обои, био-арты, сигаретные карточки, PNG-рендеры), 7 обложек, 8 карт | **только браузер** — Cloudflare блокирует curl/WebFetch; макс. разрешение: скриншоты -1080, арты -1600, обложки/карты -1920; скачивание: fetch внутри страницы → POST base64 на локальный HTTP-приёмник (порт 8931, скрипт в scratchpad) | источник текущей библиотеки; интерактивные базы (Horses/Weapons/Animals) — JS-приложения, картинки лениво, не выкачаны |
| rockstargames.com/reddeadredemption2 | официальный сайт: downloads (обои, аватары), медиа | React-приложение + **age gate** (форма с датой рождения) — нужен браузер и согласие пользователя на отправку формы | медиа на CDN akamaized.net, после age gate файлы могут качаться напрямую curl |
| rdr2.org | базы данных: персонажи, оружие, лошади, карта | проверить доступ | аналог gtabase для RDR2 |
| reddead.fandom.com | вики: биографии, факты, галереи | проверить доступ | тексты пересказывать своими словами |
| rockstarintel.com | новости Rockstar | WebFetch работает | для новостных дайджестов |

## Правила отбора

1. **Не дублировать**: перед скачиванием проверь INDEX.md.
2. **Фанатский контент** — только с указанием автора в sidecar (`license: Fan-made / community`).
3. **Тексты сайтов не копировать** — факты пересказывать своими словами со ссылкой на источник.
4. **Официальный контент Rockstar** — `license: Rockstar promo / fair use`.
