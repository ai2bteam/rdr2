# maps — карты мира и штатов

Официальная карта мира Red Dead Redemption 2 (Rockstar, скачано через gtabase.com): один
мастер-файл в максимальном разрешении и шесть региональных карт с подсветкой отдельных
территорий. Мастер-карта 7200x5400 — главный исходник для зумов, панорам и врезок по
карте; **в её углах стоят вотермарки Red Dead Base / gtabase.com**, поэтому при
использовании либо кадрируйте углы, либо указывайте источник. Региональные карты — 960x720
(Нью-Остин 1280x720). Лицензия: Rockstar promo / fair use.
