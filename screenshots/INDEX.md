# screenshots — сводный индекс

Официальные скриншоты и кадры из трейлеров Red Dead Redemption 2 и Red Dead Online
(Rockstar, скачано через gtabase.com). Всего 871 файл в трёх подпапках — это самая большая
часть библиотеки и основной источник видеоряда. Подавляющее большинство кадров в 1920x1080;
часть трейлерных скринов — широкоформатные обрезки 1920x872 и 1920x816. Лицензия по всей
папке: Rockstar promo / fair use.

**Детальные таблицы по файлам — в `INDEX.md` каждой подпапки.** Здесь только сводка.
